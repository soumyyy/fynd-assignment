# Fynd Assignment: Feedback Intelligence Dashboard

This project is a submission for the Fynd coding assignment, focusing on building an intelligent customer feedback analysis system.

## Objectives & Tasks
*   **Rating Prediction**: Predict user star ratings based on textual review content.
*   **Sentiment Analysis**: Classify feedback as Positive, Neutral, or Negative using AI.
*   **Interactive Dashboard**: A responsive admin panel to monitor feedback trends in real-time.
*   **Advanced Analytics**: Filter reviews by sentiment/rating and visualize quality trends over time.

## Tech Stack
*   **Frontend**: React, Vite, TailwindCSS, Recharts
*   **AI Backend**: Cerebras API (LLM Integration)
*   **Database**: Supabase

## Quick Setup
1.  Navigate to dashboard: `cd dashboard`
2.  Install dependencies: `npm install`
3.  Set up `.env` with your API keys (Supabase + Cerebras).
4.  Run locally: `npm run dev`
